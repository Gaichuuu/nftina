# Nftina

An independent research and commentary archive on the MetaZoo NFT ecosystem: all collection details, what holders paid, and an attempt to follow where the ETH went.

**Public site:** metazoonfts.com

Context:

- Aoki/Kalish class action (filed January 2026).
- MetaZoo Games LLC's Chapter 7 bankruptcy, case `1:24-bk-10874`, Southern District of New York (filed May 20 2024, trustee Albert Togut).

See [Legal](#legal).

Five are not what their address suggests, which is most of the work in `scripts/config.py`:

- **Mothman 1/1** is token #1017 of Aoki's own Manifold contract, not a MetaZoo deployment. It sold at Sotheby's *Natively Digital 1.2* (lot 52, October 2021) for ~$214k, settled off-chain, and has never traded on-chain.
- **Sandbox characters** are 6 assets in The Sandbox's own ASSET contract, sold for SAND on Sandbox's marketplace, so there is no ETH primary to measure.

Subset and merge rows are a presentation view, so the columns do not sum to the ecosystem totals above, which are computed once per underlying fetch key.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Required:

- `ETHERSCAN_API_KEY`
- `ALCHEMY_API_KEY`

Optional:

- `OPENSEA_API_KEY` for wallet identities.
- `GETXAPI_KEY` for the live historical tweet pull. The Wayback recovery scripts need no key.

## Pipeline

Run in order. Everything runs as a module, since the scripts import `scripts.*`.

```bash
python -m scripts.fetch_chain          # transfers + mint tx values, dedicated contracts
python -m scripts.fetch_shared         # the collections that live inside shared storefronts
python -m scripts.fetch_sales          # Alchemy secondary sales + floor prices
python -m scripts.validate_sales       # required: flag phantom (unsettled) sales
python -m scripts.analyze              # wallet P&L + per-collection stats -> public/data/
python -m scripts.trace_flows          # treasury to Aoki money graph
python -m scripts.trace_acquisitions   # what the Aoki-bound ETH bought
python -m scripts.audit_treasury_usd   # per-date USD reconciliation of the 3 treasury wallets
python -m scripts.audit_wallet_pnl     # invariant check, after any economics change
python -m scripts.fetch_token_media    # token art, collection logos, Sandbox 3D models
scripts/bunny-upload.sh media          # push art to the CDN (needs .deploy.env)
python -m scripts.build_site_data      # -> site/data/, the contract the frontend reads
```

Five things that are easy to get wrong:

- **`OPENSEA_API_KEY` has to be a classic 32-character key, not a scoped token.** A scoped self-serve token grants only authenticated-account scopes, so every account, collection and NFT endpoint returns 401 "Invalid API key" and the wallet-identity fetch resolves nothing.
- **`validate_sales` is not optional.** Alchemy's `getNFTSales` reports pre-Seaport Wyvern *order* prices even when no payment settled, which inflated one collection's reported volume by roughly 20x.
- **Etherscan's free tier caps every response at 1000 records** regardless of the offset you ask for, so pagination advances a block window rather than a page number.
- **`fetch_chain` pulls whole contracts and refuses shared ones.** A collection that is a token-ID subset of a storefront goes through `fetch_shared` instead, or you would fetch someone else's tokens.
- **Two `audit_wallet_pnl` categories are correct by design** and must not be "fixed": `loss_without_basis` (a cost basis carried forward across a plain transfer) and `sign_divergence` (an ETH gain beside a USD loss, which is what at-event pricing looks like when a wallet bought near the 2021 top).

### Tweet archive (optional, separate track)

```bash
python -m scripts.fetch_tweets              # live historical search
python -m scripts.fetch_wayback             # deleted tweets, one status-URL snapshot at a time
python -m scripts.fetch_timelines           # archived profile-page captures (dozens of tweets each)
python -m scripts.export_recovered_tweets   # -> data/evidence/recovered_tweets.json
python -m scripts.correlate                 # merge, classify promos, correlate with mint dates
```

The @MetaZooGames account is deleted, so everything about it comes from the Wayback Machine: 1,048 tweets from status-URL snapshots plus 2,651 from 95 archived profile captures, 4,709 merged. Retweets are near-absent from the status-URL method by construction, since a retweet's own URL redirects to the original and so is never archived under the retweeter.

The classifier flags an undisclosed promo when a tweet mentions a MetaZoo core term plus hype language with no `#ad` or `#partner` disclosure: 11 for Aoki, 4 since deleted, including the Mothman sale announcement and a mint-day "last chance". That count held when the corpus more than doubled.

Wayback is slow and flaky. Jobs retry with backoff, save every 25 records, and skip finished ids on rerun, so just relaunch anything that dies. It will not serve two crawlers at once, so run recovery and image downloads one at a time.

Curated, non-regenerable evidence (third-party corroboration, extracted auction pages, authored site copy) lives in the tracked `data/evidence/`, distinct from the gitignored, regenerable `data/raw/` API cache.

## The site

Vite, React 19, React Router, Tailwind v4, Zod, TypeScript and Vitest, in `web/`. A SPA that also prerenders: routes render client-side, and the production build emits static per-route HTML with real content and per-route titles, so every page is crawlable and shareable.

**It builds from a clean clone with no Python and no API keys:**

```bash
git clone <repo> && cd nftina/web && npm install && npm run build
```

That works because two build outputs are tracked on purpose: `site/data/` (the frontend data contract) and `data/media/sandbox3d/` (the six Sandbox `.gltf` models, which the build copies into `web/public` and serves same-origin, since the CDN sends no CORS header for `.gltf`). Without them the data step exits with an error and the 3D hero 404s. They are about 42 MB of a 54 MB repo, and they buy a working site.

`public/data/` is tracked for a different reason: it is the published result set, which is what makes a stated figure checkable by a reader who never runs the pipeline.

Out of git: `data/raw/` (the only thing that genuinely needs API keys to rebuild), the rest of `data/media/` (token art, served from the CDN), and `web/dist/` plus the `web/public/` copies of the two tracked sources.
